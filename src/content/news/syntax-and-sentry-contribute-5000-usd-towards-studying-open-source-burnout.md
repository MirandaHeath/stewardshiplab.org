We'd like to send a huge thank-you to [Syntax][syntax] and [Sentry][sentry] for contributing $5,000 to our
[_Understanding Burnout in Open Source_][fund] fund.

Syntax and Sentry's generous contribution will help [Miranda Heath][miranda] set up an annual survey of Open Source
maintainers, giving the community an overview of how the maintainers we all rely on are doing, and where they need
support.

While this generous donation will help a lot, we will need additional funding to be able to write this report. If you
want to help us do more for Open Source maintainers threatened by burnout, you can donate to our fund here:
