# Software Stewardship Lab Website

Deployed on [staging.stewardshiplab.org](https://staging.stewardshiplab.org).

## Setup

To install the required packages:

```bash
pnpm install
```

## Development Server

To start a development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Linting and Formatting

To lint:

```
pnpm lint:check
pnpm lint:fix
```

To format:

```
pnpm fmt:check
pnpm fmt:fix
```
